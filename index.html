Sharesat Application

UI/UX Design Mobile App

Project Overview

[Editable Draft Content] Sharesat is a crypto transaction application designed to simplify blockchain transactions for everyday users, making complex financial interactions as intuitive as messaging.

Problem

[Editable Draft Content] Cryptocurrency transactions are often confusing and intimidating for non-technical users. Most crypto apps have steep learning curves with complex interfaces that discourage adoption.

Design Direction

[Editable Draft Content] We adopted a conversational, familiar design paradigm—treating transactions like chat messages. This approach reduced cognitive load and made crypto accessible to mainstream users.

Solution

[Editable Draft Content] Created a streamlined mobile interface with intuitive workflows, clear feedback mechanisms, and a chat-like transaction flow. Users can send crypto as easily as sending a message to a contact.

Momentum Platform

UI/UX Design Web Platform

Project Overview

[Editable Draft Content] Momentum is a social event platform that enables users to discover and connect with other attendees before events take place, fostering community and engagement.

Problem

[Editable Draft Content] Event attendees often arrive not knowing anyone, missing networking opportunities and reducing overall event engagement. Pre-event connection is rare and unstructured.

Design Direction

[Editable Draft Content] Designed a platform focused on community building and discovery. The interface encourages exploration of attendee profiles and facilitates meaningful connections before the event even begins.

Solution

[Editable Draft Content] Built an intuitive discovery interface with user profiles, event details, and direct messaging capabilities. Users can preview the attendee community, find shared interests, and arrange meetups ahead of time.
